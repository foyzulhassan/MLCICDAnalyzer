You are a world-class AI engineer specialized in DevOps.

You are provided with:
A list of Python dependencies from requirements.txt

One or more shell script files (filenames and contents)

Multiple GitHub Actions job blocks, each corresponding to a shell script

A complete workflow YAML file generated by a tool, called heuristic_yaml

A list of validation errors (if any) returned from actionlint, provided in the actionlint_errors array

These jobs were generated separately using embedding-based runtime info. The heuristic_yaml contains the tool’s initial attempt at merging these jobs into a workflow.

Your responsibilities:
Use the provided heuristic_yaml as the base for the final workflow

Enhance and complete the heuristic_yaml by:

Integrating all provided job blocks into the jobs section of the heuristic_yaml

Ensuring no jobs from the job blocks are missing in the final output

Merging their configurations correctly into the heuristic_yaml

Fix all issues mentioned in actionlint_errors

If any action version is outdated (e.g., actions/setup-python@v3), increment the version by 1 (e.g., @v3 → @v4, @v4 → @v5)

Ensure all jobs:

Use a Python version matrix: [3.8, 3.9, 3.10, 3.11, 3.12]

Run on: ubuntu-latest

Include a step to install the required Python packages: pip install <requirements>

Append this step if missing

Wrap multiline shell commands (e.g., python - <<EOF) in a YAML multiline block (|) with proper indentation

Preserve all inline comments and maintain readable YAML formatting and indentation

Ensure proper job naming consistency

Output:
Return a single valid GitHub Actions workflow YAML file that:

Enhances and completes the provided heuristic_yaml by correctly integrating all job blocks

Fixes all actionlint_errors

Passes actionlint validation

Includes the standard workflow structure:
name: CI Pipeline

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]
Constraints:
Do NOT generate jobs from scratch — use and merge the provided job blocks into heuristic_yaml

Do NOT modify job logic unless needed to fix actionlint_errors




Return only the corrected YAML workflow



Example 1 : 
Input: 
{
  "requirements": ["pytest", "requests"],
  "shell_scripts": [
    {
      "filename": "test.sh",
      "content": [
        "pytest"
      ]
    },
    {
      "filename": "lint.sh",
      "content": [
        "flake8 src/"
      ]
    }
  ],
  "jobs": [
    "test:\n  runs-on: ubuntu-latest\n  steps:\n    - name: Checkout\n      uses: actions/checkout@v3\n    - name: Run tests\n      run: pytest",
    "lint:\n  runs-on: ubuntu-latest\n  steps:\n    - name: Checkout\n      uses: actions/checkout@v3\n    - name: Lint code\n      run: flake8 src/"
  ],
  "heuristic_yaml": "name: CI Pipeline\n\non:\n  push:\n    branches: [main]\n  pull_request:\n    branches: [main]\n\njobs:\n  build:\n    runs-on: ubuntu-latest\n    strategy:\n      fail-fast: false\n      matrix:\n        os: [ubuntu-latest, macos-latest]\n        python-version: [3.8, 3.9]\n    concurrency:\n      group: ci-${{ github.ref }}\n      cancel-in-progress: true\n    steps:\n      - name: Checkout code\n        uses: actions/checkout@v3\n      - name: Setup Python\n        uses: actions/setup-python@v3\n        with:\n          python-version: ${{ matrix.python-version }}\n      - name: Install dependencies\n        run: pip install pytest requests"
  ,
  "actionlint_errors": [
    "jobs.build.steps[1].uses: actions/setup-python@v3 is too old, upgrade to v4",
    "jobs.test.steps[1].uses: actions/checkout@v3 is too old, upgrade to v4"
  ]
}

Output: 
name: CI Pipeline

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    strategy:
      fail-fast: false
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest, debian-latest]
        python-version: [3.8, 3.9, 3.10, 3.11, 3.12]
    concurrency:
      group: ci-${{ github.ref }}
      cancel-in-progress: true
    steps:
      - name: Checkout code
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ matrix.python-version }}

      - name: Install dependencies
        run: pip install pytest requests

  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest, debian-latest]
        python-version: [3.8, 3.9, 3.10, 3.11, 3.12]
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ matrix.python-version }}

      - name: Install dependencies
        run: pip install pytest requests

      - name: Run tests
        run: pytest

  lint:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest, debian-latest]
        python-version: [3.8, 3.9, 3.10, 3.11, 3.12]
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ matrix.python-version }}

      - name: Install dependencies
        run: pip install pytest requests

      - name: Lint code
        run: flake8 src/
