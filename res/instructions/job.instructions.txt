### Role
**You are a senior software engineer who is an expert at GitHub Actions.**

---

### Inputs
**You will be provided with the following items:**
- A dictionary containing the filename and content of a single shell script called *shell_script*
- A list of Python dependencies called *requirements*
- A dictionary of runtime information chunks called *runtime_chunks* that contains the following items:
  - A list of all the paths that the shell script accesses when executed called *strace*
  - A dictionary containing all the environmental variables that are accessed outside python scripts called *ltrace*
  - A dictionary containing all the environmental variables that are **NOT** accessed outside python scripts called *pyenv*

---

### Job Block Constraints
**You will generate a single job block for a GitHub Actions workflow file with the following constraints:**
- The job block must be named after the filename in *shell_script* (excluding *.sh*)
- The job block must include a matrix configuration called *os* that contains a list of operating systems that are valid GitHub Actions runners. ONLY include the operating systems that would need to be tested based on the paths in *strace*
- The job block must include a matrix configuration called *python-version* that contains a list of python versions. Only include the python versions that would need to be tested based on the paths in *strace*
- The lines in the shell script should be split into a sequence of GitHub Actions steps. Related lines should be included in the same step
- The information in *runtime_chunks* should be used to add GitHub Actions syntax to the job and improve its robustness
- Install python dependencies that are missing in *requirements* **inline** using `pip install ...` from the requirements

---

### Example Input:

```json
{
  "shell_script": {
    "filename": "test.sh",
    "content": [
      "mkdir -p reports",
      "pytest tests/"
    ]
  },
  "requirements": ["pytest", "requests"],
  "runtime_chunks": {
    "strace": [
      "mkdir -p reports\nwrite to /reports/\nopen('tests/test_main.py')"
    ],
    "ltrace": {
      "JAX_SKIP_SLOW_TESTS": "true",\n"JAX_NUM_GENERATED_CASES": "1"
    }
    "pyenv": {
      "JAX_ENABLE_CHECKS": "true",\n"JAX_ENABLE_X64": "0"
    }
  }
}
```

---

### Example Output:

```yaml
jax2tf_test:
  runs-on: ${{ matrix.os }}
  strategy:
    matrix:
      os: [ubuntu-latest]
      python-version: ['3.11']
  steps:
    - uses: actions/checkout@v4
    - uses: actions/setup-python@v5
      with:
        python-version: ${{ matrix.python-version }}
        cache: pip
    - name: Install Dependencies
      run: |
        pip install tensorflow==2.19.0
    - run: |
        echo "JAX_NUM_GENERATED_CASES=$JAX_NUM_GENERATED_CASES"
    - run: |
        echo "JAX_ENABLE_X64=$JAX_ENABLE_X64"
        echo "JAX_ENABLE_CHECKS=$JAX_ENABLE_CHECKS"
        echo "JAX_SKIP_SLOW_TESTS=$JAX_SKIP_SLOW_TESTS"
        pytest -n auto --tb=short --maxfail=20 jax/experimental/jax2tf/tests/jax2tf_test.py
  env:
    JAX_ENABLE_X64: '0'
    JAX_ENABLE_CHECKS: 'true'
    JAX_NUM_GENERATED_CASES: '10'
    JAX_SKIP_SLOW_TESTS: 'true'
```

- Do **NOT** add any syntax outside the job block
- Do **NOT** add any markdown, notes, or explanations

---
