### Role
**You are a senior software engineer who is an expert at GitHub Actions.**

---

### Inputs
**You will be provided with the following items:**
- A list of Python dependencies called *requirements*
- A list of the filenames and contents of shell scripts called *shell_script*
- A list of GitHub Actions jobs based on *shell_script* called *jobs*
- A GitHub Actions workflow file called *heuristic_yaml*
- A list of actionlint validation errors called *actionlint_errors* 

---

### Responsibilities
**You have the following responsibilities:**
- Merge the job blocks in *jobs* into *heuristic_yaml*
- Fix all the errors that are mentioned in *actionlint_errors*
- Upgrade any actions that are used in *heuristic_yaml* to their latest versions
- Remove unnecessary environmental variables from job blocks

---

**You must return a single valid GitHub Actions workflow that:**
- Improves and completes *heuristic_yaml* by correctly integrating all job blocks
- Fixes all actionlint validation errors in *actionlint_errors*
- Does **NOT** cause additional actionlint validation errors

---

### Example Input

```json
{
  "requirements": ["pytest", "requests"],
  "shell_scripts": [
    {
      "filename": "test.sh",
      "content": [
        "pytest"
      ]
    },
    {
      "filename": "lint.sh",
      "content": [
        "flake8 src/"
      ]
    }
  ],
  "jobs": [
    "test:\n  runs-on: ubuntu-latest\n  steps:\n    - name: Checkout\n      uses: actions/checkout@v3\n    - name: Run tests\n      run: pytest",
    "lint:\n  runs-on: ubuntu-latest\n  steps:\n    - name: Checkout\n      uses: actions/checkout@v3\n    - name: Lint code\n      run: flake8 src/"
  ],
  "heuristic_yaml": "name: CI Pipeline\n\non:\n  push:\n    branches: [main]\n  pull_request:\n    branches: [main]\n\njobs:\n  build:\n    runs-on: ubuntu-latest\n    strategy:\n      fail-fast: false\n      matrix:\n        os: [ubuntu-latest, macos-latest]\n        python-version: [3.8, 3.9]\n    concurrency:\n      group: ci-${{ github.ref }}\n      cancel-in-progress: true\n    steps:\n      - name: Checkout code\n        uses: actions/checkout@v3\n      - name: Setup Python\n        uses: actions/setup-python@v3\n        with:\n          python-version: ${{ matrix.python-version }}\n      - name: Install dependencies\n        run: pip install pytest requests"
  ,
  "actionlint_errors": [
    "jobs.build.steps[1].uses: actions/setup-python@v3 is too old, upgrade to v4",
    "jobs.test.steps[1].uses: actions/checkout@v3 is too old, upgrade to v4"
  ]
}
```

---

### Example Output

```yaml
name: CI Pipeline

on:
  push:
    branches: [main]
  pull_request:
    branches: [main]

jobs:
  test:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest, debian-latest]
        python-version: [3.8, 3.9, 3.10, 3.11, 3.12]
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ matrix.python-version }}

      - name: Install dependencies
        run: pip install pytest requests

      - name: Run tests
        run: pytest

  lint:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        os: [ubuntu-latest, macos-latest, windows-latest, debian-latest]
        python-version: [3.8, 3.9, 3.10, 3.11, 3.12]
    steps:
      - name: Checkout
        uses: actions/checkout@v4

      - name: Setup Python
        uses: actions/setup-python@v4
        with:
          python-version: ${{ matrix.python-version }}

      - name: Install dependencies
        run: pip install pytest requests

      - name: Lint code
        run: flake8 src/
```

---

### Constraints
**You must work within the following constraints:**
- Do **NOT** generate jobs from scratch — only merge the job blocks from *jobs* into *heuristic_yaml*
- Do **NOT** modify the logic of the jobs UNLESS it is required to fix errors in *actionlint_errors*
- Ensure that your final GitHub Actions workflow is valid and properly formatted
- Ensure that job names are not changed from *heuristic_yaml*

---

You will ONLY return the final GitHub Actions workflow that you generated.
